# Bitstream Podcast Network App

Mobile-first podcast network app for **Bitstream.fm**. UI mockups generated with [Stitch](https://stitch.withgoogle.com) (project: "Bitstream Podcast Network App") — exported 2026-10-07, polished (Follow-button state fix, Shop trimmed to real products, Everyday AI restored to subscriptions).

Dark premium audio aesthetic: deep black `#0A0A0B`, electric green `#39FF14`. Brand line: **"Zero Filler. All Value."**

## Shows

1. W For News in the Chat — hourly streamer-style news
2. Bitstream — daily tech podcast
3. Everyday AI — daily AI news
4. AI Money — daily AI business
5. Bar Exam — weekday hip-hop news
6. Block by Block — crypto news, 3x daily

## Screens

| Screen | Folder |
|---|---|
| Home feed — continue listening, latest drops | `screens/home_feed/` |
| Discover — search, topics, trending | `screens/discover/` |
| Show detail — W For News in the Chat | `screens/show_detail_w_for_news/` |
| Full audio player — speed, sleep timer, queue | `screens/full_audio_player/` |
| Clips — vertical 60s highlight feed | `screens/clips/` |
| Library — subscriptions, downloads, history | `screens/library/` |
| Shop — prompt packs + merch (DEMO) | `screens/shop/` |
| Settings — playback, downloads, notifications | `screens/settings/` |

Each screen folder has `index.html` (self-contained mockup) and `preview.png`.

Design tokens: `design-system/DESIGN.md` ("Obsidian Audio").

## Status

UI mockups — all content labeled DEMO. No backend, no real audio, no real commerce.
